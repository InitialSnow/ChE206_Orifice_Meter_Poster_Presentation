# ChE206 Orifice Meter Website

Static, GitHub Pages-ready website for the **Calibration of Orifice Meter** poster presentation.

## Included
- Mobile-first scrolling website
- Interactive SVG orifice-meter visualization
- Dynamic Q and diameter-ratio (β) controls
- Animated flow and vena-contracta movement
- Illustrative pressure-head graph
- Supplied unfinished poster preview
- Web-generated PDF rendition of the supplied lab report
- Placeholder reports for participants 02–09
- Reference list based on the supplied report

## Replace before publishing
1. `assets/poster/poster-final-placeholder.pdf` → final poster PDF.
2. `assets/reports/participant-02.pdf` through `participant-09.pdf` → final reports.
3. Update participant names in `script.js`.
4. Update `references.json` with final URLs/DOIs.
5. Verify the simulation parameters/equations against the final ChE206 lab manual before presenting.

## GitHub Pages
1. Create a GitHub repository.
2. Upload all files in this folder.
3. Push to the default branch.
4. In GitHub: Settings → Pages → Deploy from branch → choose the repository branch and `/root`.
5. Use the resulting Pages URL in the poster QR code.

No backend is required.
